## 🚀 Features

- **User Registration & Login**
- **Submit Lost Items**
- **Submit Found Items**
- **Automatic Matching** of lost/found items using NLP (`scikit-learn`)
- **Image Upload** for items
- **CSV-based storage** (lightweight, no database required)
- **Admin Dashboard** with analytics (Streamlit)
- **Responsive Frontend** (Streamlit)

---

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: Streamlit
- **Dashboard**: Streamlit
- **Storage**: CSV Files
- **Matching Engine**: NLP with TF-IDF (scikit-learn)
- **CORS Support**: flask-cors
